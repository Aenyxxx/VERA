## Other repo facts the manuscript must follow
- Name: **VERA — Verified Evaluation and Recruitment Assistant**; title: *VERA: An NLP-Assisted Resume Matching using Sentence-BERT with Cosine Similarity and Weighted Sum Model for Confiable Manpower Solutions Inc.* (final wording confirmed Oct 13; use "with", not "plus")
- Matching: first-time = skills only; experienced = 50% skills + 50% experience; skills only when the vacancy has no experience text (no minimum years, decision 11). Whole-resume fallback per missing section (decision 12).
- Scoring: interview score 0–100 from the two-level WSM ((mean − 1) ÷ 4 × 100 per section, then weighted by section); final = (matching + interview) ÷ 2, 0–100 (decision 1).
- Flow: prescreen → matching → threshold (not qualified → "Not shortlisted", talent pool, matched to new vacancies, invitation accept/decline) → waiting pool → automatic shortlist → document verification → online interview → 15-item rating → interview score (two-level WSM) → final score → combined ranking → HR notifies → applicant confirms → endorsement batch sent to client (**one endorsement packet per applicant: competency evaluation + resume**, decision 21) → **final interview scheduled and applicant notified → status updates → For hiring → Hired / Not hired** (not hired → automatic rematch) → post-hiring details.
- Rules: one ongoing application per applicant; one application per vacancy; applicants never see the client company; one current resume (replaceable); rating reuse instead of a second interview; talent pool (one active entry); company block 1 year.
- Client companies are not users; client replies are encoded by HR. Admin manages HR accounts.
